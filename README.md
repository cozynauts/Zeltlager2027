# Sindlinger Zeltlager 2027 – GitHub Pages Testversion

**Nur Demo. Keine echten Kinder- oder Gesundheitsdaten eingeben.**

## Veröffentlichen
1. Neues öffentliches GitHub-Repository `zeltlager-2027` erstellen.
2. `index.html` und `.nojekyll` in das Stammverzeichnis des Repositories hochladen (nicht den übergeordneten Ordner).
3. Repository → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Nach Veröffentlichung unter `https://<BENUTZERNAME>.github.io/zeltlager-2027/` testen.

## Funktionen
Informationen, mehrstufiges Formular, Validierung, druckbare Anmeldung (Browser: Als PDF speichern), Packliste. Keine Datenbank, kein automatischer Versand.

## Vor Produktivstart
Datenschutztexte, Einwilligungen, Unterschrift, Hostingfreigabe und sichere API abstimmen. Keine Gesundheitsdaten in Mailto, URLs, Analytics oder öffentliche Repositories schreiben. Server-API muss serverseitig validieren, Zugriffe schützen, Speicherung verschlüsseln und sichere Benachrichtigungen auslösen.
